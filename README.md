# Control de Gastos

Proyecto de práctica en **Java**, desarrollado paso a paso, con el objetivo de aprender a construir un programa desde cero y desarrollar la lógica de programación.

La idea es avanzar **una fase a la vez**, comprendiendo lo que se está haciendo antes de añadir nuevos conceptos.

## Primera versión — Registrar un gasto

En esta primera versión, el programa permite:

* Pedir el valor de un gasto.
* Pedir la descripción del gasto.
* Mostrar el gasto registrado.

### Lo aprendido en esta fase

Durante la construcción de esta primera versión, además de aprender a escribir el código, se trabajó en:

* Comprender la función de las variables.
* Utilizar `double` para valores numéricos.
* Utilizar `String` para textos.
* Utilizar `Scanner` para recibir datos del usuario.
* Utilizar `nextDouble()` para recibir un valor numérico.
* Utilizar `nextLine()` para recibir texto.
* Identificar errores durante la ejecución.
* Comprender por qué ocurre un problema con `Scanner` al utilizar `nextDouble()` seguido de `nextLine()`.
* Analizar el problema y proponer una corrección adecuada para conseguir que el código funcione correctamente.

### Objetivo del proyecto

Este proyecto no busca solamente crear un programa funcional, sino **entender el proceso de construcción del código**, aprender a identificar errores y desarrollar progresivamente la capacidad de resolver problemas por cuenta propia.
